# 산출물 컬럼 정의

## 파일

| 파일 | 생성 | 내용 |
|---|---|---|
| `{workdir}/work/{id}.json` | run_extract | 사이트별 상세 — findings, 하단/상단 텍스트 일부, override 적용여부 |
| `{workdir}/outputs/extract_{기준일}.csv` | run_extract | 게재값 + 근거·위치·확신도 (등록정보 대조 전) |
| `{workdir}/outputs/verify_{기준일}.csv` | compare_registry | extract + 등록값·대조판정 + 확인필요 플래그 |
| `{workdir}/outputs/final/{기준일}_필요적게재사항_점검결과.xlsx` | finalize | 검증시트/확인필요/통계/입력원본 |

## 공통 컬럼

| 컬럼 | 의미 |
|---|---|
| `언론사_id` | 입력의 식별자 (없으면 `ROW00001` 자동 부여) |
| `제호_등록` | 등록정보상 제호 (화면 게재 제호는 `제호_게재값`) |
| `메인_url` / `최종URL` / `리다이렉트` | 입력 URL / 실제 도달 URL / 도메인 변경 여부 |
| `접속결과` | `가능` / `불가` / `URL없음` / `내용없음` |
| `js_의심` | `Y` = 텍스트가 거의 없는 JS 렌더링 페이지 → 브라우저 판독 필요 |
| `운영상태` | 입력 xlsx 의 값 그대로 (참고용). 판정은 아래 `홈페이지_운영현황` 이 한다 |

## 홈페이지 운영현황 컬럼 (지침 I) — `md_core/operation.py` 가 채운다

**이 관문을 `있음` 으로 통과한 매체만 필요적 게재사항 점검 대상이다.**

| 컬럼 | 값 |
|---|---|
| `홈페이지_운영현황` | `있음` / `없음` |
| `운영현황_로직` | `I-1` 매체명 동일 / `I-2` 매체명 상이·뉴스 있음 / `I-3` 매체명 상이·뉴스 없음 / `I-4` 오류페이지·접속불가·파킹 |
| `매체명_동일` | `Y` / `N` / `확인불가` (상단 로고 → 하단 정보 순으로 확인) |
| `뉴스_있음` | `Y` / `N` / `확인불가` (카테고리·제목에 '기사'/'뉴스' 가 있으면 뉴스로 본다) |
| `운영현황_사유` | 판정 근거 문장. `I-2`·`I-3` 은 사람이 반드시 읽어야 한다 |

`I-3`·`I-4` 는 지침상 **포털검색** 대상이다 (`resolve_failed.py`).

## 항목별 컬럼 (10항목 × 5)

항목: `제호`, `제호 영문`, `등록번호`, `등록연월일`, `발행인`, `편집인`, `발행연월일`, `발행소 주소`, `발행소 전화번호`, `창간일`

| 접미사 | 의미 |
|---|---|
| `_게재값` | 화면에서 추출한 값. 빈칸 = 미검출, `해당사항 없음` = 없음을 확인 |
| `_위치` | `하단` / `상단` / `기타` / `없음`. 지침 R17 상 `기타` 도 **게재로 인정**하되 검증 대상 |
| `_확신도` | `high` / `mid` / `low` (기준은 field_rules.md) |
| `_추출방법` | 아래 표 참조 |
| `_근거` | 원문 스니펫(±45자). 사람이 눈으로 확인하는 핵심 컬럼 |

### `_추출방법` 값

| 값 | 의미 |
|---|---|
| `라벨` | 항목 고유 라벨 뒤(또는 앞)에서 값을 읽음 — 가장 확실 |
| `형식매칭(라벨없음)` | 라벨 없이 형식(전화·등록번호·주소)만 보고 잡음 |
| `라벨없음_등록이름일치` | 등록된 성명과 문자열이 같아 인정 |
| `병기(발행·편집인)` | `발행·편집인` 병기 표기에서 양쪽 인정 |
| `등록번호 병기 날짜` | `등록번호 : 세종 아00023(2014년2월21일)` 형태 |
| `지침R7-2 대체(등록연월일\|창간일)` | 발행연월일 자리에 다른 이름의 날짜 (지침 R7-2) |
| `지침R7-3 기사 업로드 날짜` | 기사목록·기사 상세의 업로드 날짜 (지침 R7-3) |
| `지침R10-2 대체(발행연월일\|창간일)` | 등록연월일 자리에 다른 이름의 날짜 (지침 R10-2) |
| `이름항목대체(청소년보호책임자 등)` | 발행인·편집인을 다른 이름 항목으로 인정 (지침 R13-2/R15-2) |
| `지침교차규칙(R7비고\|R10비고\|R12비고\|R14비고)` | 항목 간 전이로 준수 (field_rules.md 교차규칙) |
| `발행일검증(확인경로)` | `verify_pubdate.py` 전용 검증 결과 |
| `title추정` | title 태그 폴백 — 화면 게재 증거가 아니므로 확인필요 |
| `수동` / `미검출` | override 로 넣은 값 / 못 찾음 |

대조 5항목(`등록번호`,`발행인`,`편집인`,`발행소 주소`,`발행소 전화번호`)에는 추가로:

| 컬럼 | 값 |
|---|---|
| `_등록값` | 등록정보상 값 |
| `_대조` | `일치` / `일치(라벨없음)` / `부분일치` / `불일치` / `미검출` / `등록값없음` |

## 요약 컬럼

| 컬럼 | 의미 |
|---|---|
| `필수8_게재수` | 필수 8항목 중 게재 확인된 수 (0~8) |
| `미게재_항목` | 미검출 항목명 목록 |
| `준수여부_8항목` | `준수` / `미준수` / `홈페이지없음` (**AI 초안 판정**) |
| `준수여부_LLM` | **최종 판정.** 같은 3분류. `준수여부_규칙` 은 대조·감사용 동결 스냅샷 |
| `판단근거` | 지침 R8 비고 — 대체 인정·교차규칙으로 준수가 된 항목만 `항목=근거` 로 모아 적는다 |
| `불일치_항목` | 대조에서 불일치·부분일치가 난 항목 |
| `등록정보_상이` / `_사유` | **제9조 변경등록** 확인 대상. 제21조 게재의무 위반이 아니다 |
| `확인필요` | `Y` = 사람 검증 대상 |
| `확인필요_사유` | `[운영현황]` / `[수집]` / `[검색]` / `[비전]` / `[추출]` / `[증빙]` / `[발행일]` 표지로 누적 |
| `증빙_경로` / `증빙_누락` | 스크린샷 경로 / 핵심 증빙이 없으면 사유 |
| `비고` | override 적용·접속 실패 등 메모 |

## 해석 주의

- `준수여부` 는 **자동 초안**이다. 확인필요=Y 인 행은 검증 전에는 확정하지 마라.
- **`홈페이지없음` 은 미준수가 아니다.** 지침 I 에서 걸러진 점검 제외 건이므로
  과태료 대상 집계에 넣으면 안 된다. 준수율의 분모도 `홈페이지_운영현황=있음` 이다.
- 미검출이 곧 미게재는 아니다 — 이미지 표기·JS 렌더링·비정형 레이아웃일 수 있다.
- 대조 `등록값없음` 은 입력 xlsx 에 해당 등록정보 컬럼이 없거나 비어 있는 경우다 (매체 잘못이 아니다).

# override JSON 스키마 (수동 판독)

룰 추출이 실패·부정확한 사이트를 네가 직접 판독해 남기는 파일.
위치: `{workdir}/overrides/{domain}.json` (domain 은 최종 URL 의 호스트, `www.` 제거).

```json
{
  "domain": "example.co.kr",
  "footer_selector": "#footer .company-info",
  "header_selector": ".top-date",
  "fields": {
    "발행인": {"값": "홍길동", "근거": "발행·편집인 : 홍길동", "위치": "하단"},
    "편집인": {"값": "홍길동", "근거": "발행·편집인 : 홍길동", "위치": "하단"},
    "발행연월일": {"값": "2026-07-27", "근거": "상단 '최종수정 2026.07.27'", "위치": "상단"},
    "발행소 주소": {"값": "해당사항 없음", "근거": "하단에 주소 없음", "위치": "없음"}
  },
  "rendered_html": "file:///.../example_rendered.html",
  "pinned": true,
  "notes": "JS 렌더링. Chrome 으로 저장한 HTML 로 판독"
}
```

## 필드

| 키 | 필수 | 의미 |
|---|---|---|
| `domain` | ✅ | 대상 도메인 (파일명과 일치) |
| `footer_selector` | | 하단 블록 CSS selector. 주면 룰 추출이 이 블록을 하단으로 사용 |
| `header_selector` | | 상단 블록 CSS selector (발행연월일 탐색 범위) |
| `fields` | | 항목명 → `{값, 근거, 위치}`. 룰 결과를 덮어쓰고 `추출방법=수동`, 확신도 `high` |
| `rendered_html` | | JS 사이트에서 Chrome 으로 저장한 HTML 경로(`file://`). 있으면 fetch 대신 이 파일을 읽는다 |
| `pinned` | | `true` 면 자동 재발굴·자동 덮어쓰기 금지 (사용자 수동 패치 보호) |
| `notes` | | 판독 근거·주의사항. 다음 실행 때 같은 시행착오 반복 방지 |

**항목명은 반드시 아래 문자열 그대로**:
`제호`, `제호 영문`, `등록번호`, `등록연월일`, `발행인`, `편집인`, `발행연월일`, `발행소 주소`, `발행소 전화번호`, `창간일`

`위치` 는 `하단` / `상단` / `기타` / `없음` 중 하나. 미게재를 확정했으면 값에 `해당사항 없음` 을 넣고 `위치: "없음"`.

## 작성 체크리스트

1. `fetch_masthead.py` 로 **실제 텍스트를 보고** 적었는가 (추측 금지).
2. 값이 메인 상·하단에 있는가 — 별도 페이지(회사소개 등)면 미게재다.
3. 발행연월일(최신 기사 날짜)과 등록연월일(과거 등록일)을 헷갈리지 않았는가.
4. `근거` 에 원문 문구를 그대로 짧게 남겼는가 (사람 검증용).
5. 이미지로만 표기된 항목은 값을 넣지 말고 `notes` 에 "이미지 표기 — 스크린샷 확인" 을 남겨라.
